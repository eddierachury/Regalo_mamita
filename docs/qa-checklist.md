# QA Checklist
- Backend API: validar 200 en endpoints /api/* y estructura JSON.
- Frontend rendering: carga secciones y estado de carga/error.
- Media loading: imágenes visibles y fallback de rotas.
- Music toggle: play/pause manual, sin autoplay, fallback si falta archivo.
- Video placeholder: mostrar mensaje si MP4 no está disponible.
- Responsive: móvil/tablet/escritorio.
- Accessibility baseline: alt text, contraste básico, botones accesibles.
- Emotional experience: tono cálido, elegante, nostálgico y alegre.
