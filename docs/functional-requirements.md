# Functional Requirements
## Product vision
Sitio emocional de cumpleaños tipo museo digital.
## User journey
Hero → Timeline → Gallery → Video → Carta → Mensaje final.
## Main sections
Hero, timeline, galería, video Manim, carta interactiva, celebración final.
## Data needed
profile.json, timeline.json, gallery.json, letter.json, settings.json.
## Acceptance criteria
Carga de datos, responsive, fallback de errores multimedia, no autoplay música.
## Out of scope v1
CMS, auth, DB, descarga de música, creación de animación Manim.
